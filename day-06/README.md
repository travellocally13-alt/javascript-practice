# Order Analyzer

A JavaScript mini-project that analyzes customer orders and generates a business report.

## Features

- Validates customer orders
- Identifies invalid orders
- Calculates total value of valid orders
- Counts valid and invalid orders
- Identifies VIP customers
- Generates a simple business report

## Technologies

- JavaScript
- Node.js

## How to Run

```bash
node order-analyzer.js

```

## Example Output

Total Orders: 7

Valid Orders: 4

Invalid Orders: 3

Total Value of Valid Orders: 30000 CZK

VIP Customers:

Anna - 7500 CZK
Sarah - 12000 CZK
